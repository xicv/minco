## Goal

Make the framework materially safer to adopt before moving GarmentIQ or CGSP:
reconcile duplicated repository truth, make HTTP header policy typed and
plugin-driven, add an opt-in SQS Lambda worker runtime with partial-batch
semantics, strengthen OpenAPI policy validation, measure the default facade and
native Lambda artifacts, and publish a practical incremental-adoption guide.

## Non-goals

- migrate or edit GarmentIQ or CGSP;
- deploy or mutate AWS;
- upload crates, create release tags, or publish artifacts;
- add an ORM, runtime plugin scanning, dynamic plugin loading, a global service
  locator, or hidden worker schedules;
- silently stabilize every beta plugin or represent local evidence as live-cloud
  proof.

## Acceptance

- deterministic validation rejects repository-truth drift with stable diagnostic
  codes and fixture coverage;
- applications and installed plugins can contribute exact CORS request,
  response-exposure, and sensitive-header policy without wildcard broadening;
- `minco-aws-worker` handles SQS partial batch responses, missing identifiers,
  empty bodies, bounded payloads, deterministic failures, and FIFO-safe ordering
  without hidden scheduling;
- OpenAPI validation closes open-object, idempotency, authentication, and
  Problem Details policy gaps with positive and negative fixtures;
- no-default and default facade builds remain free of SQLx and AWS SDK crates,
  and measured build/artifact evidence is recorded without inflating the default
  surface;
- adoption, compatibility, stability, and release notes distinguish published
  `0.1.1`, the workspace `0.2.0` candidate, and remaining external validation
  gaps;
- the complete exact-source local gate and multi-package publication dry run
  pass before a draft pull request is opened.
